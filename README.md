# Gametracker – Releases

Hier liegen nur die fertigen Android-Dateien (APK) des Gametrackers, kein Quellcode.

**Erste Installation:** Unter [Releases](https://github.com/DBocken/gametracker-releases/releases/latest) die neueste `gametracker-….apk` auf das Handy laden und öffnen. Android fragt einmal, ob Installationen aus dieser Quelle erlaubt sind.

**Updates:** In der App unter **Mehr → App-Update**. Die App lädt die neue Version von hier und öffnet die Installation; deine Spiele, Sitzungen und Stände bleiben erhalten.
